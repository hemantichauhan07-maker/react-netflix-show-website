# 🎬 Netflix Show App

A Netflix-inspired movie and TV show web application built using **React.js** and **Vite**. This project uses The Movie Database (TMDB) API to fetch and display movie and TV show information.

## 🚀 Features

- Browse movies and TV shows
- Fetch movie data using the TMDB API
- Display movie posters and details
- Search for movies (if implemented)
- Responsive user interface
- React component-based structure
- Fast development with Vite

## 🛠️ Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- Tailwind CSS
- React Router DOM
- TMDB API
- Vite

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/react-netflix-show-app.git
```

### 2. Open the project folder

```bash
cd react-netflix-show-app
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure the TMDB API

Create a `.env` file in the project root and add your TMDB API configuration:

```env
VITE_TMDB_BASE_URL=https://api.themoviedb.org/3
VITE_TMDB_API_KEY=your_tmdb_api_key
```

Use the environment variable name that matches your actual project code. Keep your API key private and never upload real credentials to GitHub.

### 5. Start the development server

```bash
npm run dev
```
If you want to show the required variable names, create a `.env.example` file with placeholder values.
